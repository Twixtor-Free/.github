## 🧠 Overview

Twixtor is a retiming plug-in from RE:Vision Effects that rebuilds intermediate frames with optical flow instead of blending neighbours — used for slow motion, speed ramps and frame-rate conversion.

On a Windows machine it runs as a plug-in suite that loads inside Adobe After Effects, Adobe Premiere Pro. Typical use is retiming and optical flow work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🐢 Optical Flow Retiming | Generates new frames from motion vectors, so slow motion does not show doubled frames. |
| 🎚️ Speed Ramps | Speed is keyframed over time, including freezes and reversed sections. |
| 🧭 Motion Vectors | Sensitivity, smoothing and tracking controls decide which parts of the frame follow the flow. |
| 🩹 Artefact Controls | Edge and occlusion handling reduce tearing around fast-moving or crossing objects. |
| 🎞️ Frame Rate Conversion | Converts 24 to 60 fps or the reverse while keeping motion continuous. |
| 🔗 Host Integration | Runs as an effect on the clip, with parameters exposed in the host timeline. |

## Additional Information for Windows Users

Settings created in Twixtor are stored in the plug-in's own preset folder, so a reinstall keeps user presets and replaces only program files.

Removing the plug-in goes through the host application's plug-in manager or the Windows uninstall entry, depending on how it was registered.
